# QR Studio 要件定義書

> QRコードは株式会社デンソーウェーブの登録商標です。


## 1.1 対応するシンボル（すべて公開規格）
| 種別 | 規格 | 範囲 |
|---|---|---|
| QRコード モデル2（既定） | ISO/IEC 18004:2015 | 型番1〜40、誤り訂正 L/M/Q/H、マスク0〜7（自動／手動） |
| マイクロQR | ISO/IEC 18004 | M1〜M4（M1は誤り検出のみ、M4は L/M/Q まで） |
| rMQR（長方形） | ISO/IEC 23941:2022 | R7x43〜R17x139 の32サイズ、誤り訂正 M/H |
| 連結（構造的連接） | ISO/IEC 18004 | モデル2で最大16シンボル。パリティは自動計算 |

## 1.2 データと符号化
- モードは数字・英数字・8bitバイト・漢字（Shift_JIS）の4つ。ECI と FNC1（GS1）も指定できる。
- 既定は「自動」で、最短になるように複数モードを混在させる。上級者向けに、区間ごとにモードを手動指定できるエディタも用意する。
- 入力の種類：
  - URL、テキスト、電話（`tel:`）、SMS（`SMSTO:`）、メール（`mailto:` / `MATMSG:`）
  - Wi-Fi（`WIFI:` 形式。特殊文字はエスケープする）
  - vCard 3.0、MeCard
  - 位置情報（`geo:`）、カレンダー（`BEGIN:VEVENT`）
  - 複数URL（改行区切りで1つのQRに入れる）
  - バイナリ（ファイルのアップロード、または16進数の入力）
- 容量オーバー時の動作：
  1. より大きい型番を提案する
  2. 誤り訂正レベルを下げることを提案する
  3. 連結QRに分割することを提案する

  この順に提案し、残り容量（ビット数・文字数）を常に表示する。
- 一括生成：複数行のテキストまたはCSVを入力すると、1行ごとに1枚のQRを作る。結果は一覧表示とZIP保存（PNG/SVG）で受け取れる。

## 1.2.1 容量テーブル（部分表示）
選んでいる種類と設定で、どれだけのデータを入れられるかを表で示す。

- 列：
  - 型番またはサイズ（1〜40 / M1〜M4 / R7x43〜R17x139）
  - 誤り訂正
  - 数字・英数字・バイト・漢字それぞれの最大文字数
  - データのビット数
  - 連結時の合計（連結数が2〜16のとき）
- 部分表示：
  - 既定では、今の設定の行を中心に前後数行だけを表示する。
  - 設定を変えると表示範囲が追従し、今の行を強調する。
  - 「全件表示」で全行（モデル2で160行、rMQRで64行、マイクロQRで8行）を開ける。
  - 誤り訂正レベルでの絞り込みもできる。
- 入力との連動：
  - 今の入力が収まる行に ✓ を付け、収まる中で最小の型番を示す。
  - 今の行には使用率のバーを出す。
  - 行をクリックすると、その型番と誤り訂正が設定に反映される。
- 計算方法：文字数は表に固定値で持たず、エンコーダと同じ表（データのコード語数）から算出する。
  - モードの指示子と文字数の指示子のビット数を差し引いて求める。
  - M1 と M3 は、末尾のコード語が4bitであることも考慮する。
  - 連結では、1シンボルあたり20bitのヘッダを差し引く。
  - こうすることで、エンコーダの挙動と表示が必ず一致する。

## 1.3 見た目と出力
- セルのサイズ（px/mm）、出力サイズ、余白（既定4セル、マイクロQRとrMQRは既定2セル）を設定できる。
- 前景色・背景色・透過背景を設定できる。コントラストが不足すると警告する。
- 中央には、ロゴ画像または囲み文字（例：①）・短いテキストを置ける。置くと誤り訂正Hを推奨し、占有面積の上限も警告する。
- 周囲に文字入りのラベル枠（例：「SCAN ME」）を付けられる。上下の位置とフォントを選べる。
- 読取検証：装飾まで含めた画像を zxing-wasm で実際に読み取り、OK か NG かを表示する。zxing-wasm は必要になった時点で読み込む。
- 出力：PNG / SVG の保存、クリップボードへのコピー、生成履歴（IndexedDB、最大100件、削除可能）。

- 印刷向けの出力：mm単位とDPI（72〜1200）を指定してPNGを作る（例：30mm角を350dpi）。印刷時のセルの大きさが0.25mm未満になると警告する。SVGはmm単位で書き出す。
- 一括生成の上限は1,000件。Web Workerで処理し、進捗を表示し、途中で中止できる。

## 1.3.1 画面と言語
- 日本語と英語を切り替えられる。既定はブラウザの言語設定に従い、選んだ言語は保存する。文言は `src/lib/i18n/{ja,en}.ts` にまとめる。
- PCとスマホを同等に扱う。
  - PC：左に入力と設定、右にプレビューと容量テーブルの2列。
  - スマホ：プレビューを上部に固定し、その下に入力、設定、容量テーブルを縦に並べる。

## 1.3.2 テーマとフォント
- **テーマ**
  - 「端末に合わせる」「ライト」「ダーク」の3つから選ぶ。既定は「端末に合わせる」。
  - 選んだテーマは localStorage に保存する。
  - 仕組み：`<html data-theme>` と CSS 変数の色トークンで切り替える。「端末に合わせる」のときは `prefers-color-scheme` を監視する。
  - `<meta name="theme-color">` をライト用・ダーク用の2本用意し、手動で切り替えたときは JS で更新する。manifest の `theme_color` と `background_color` も設定する。
  - 初回表示のちらつき防止：`index.html` の先頭に小さなインラインスクリプトを置き、描画前に `data-theme` を決める。CSP ではこのスクリプトの hash だけを許可する。
  - 注意：プレビューのQR自体の色は、テーマではなく利用者が指定した前景色・背景色に従う。
- **フォント**
  - JetBrains Mono（`@fontsource-variable/jetbrains-mono` v5.3、OFL-1.1）をバンドルに同梱する。
  - 外部CDNは使わない。woff2 を Service Worker で事前キャッシュし、オフラインでも表示できるようにする。
  - 読み込むのは latin と latin-ext のサブセットのみ。`font-display: swap` を指定する。
  - JetBrains Mono には日本語の字形がない。かな・漢字は、端末に入っている日本語フォントで補う。
    - 指定：`font-family: "JetBrains Mono Variable", "Hiragino Sans", "Noto Sans JP", "Yu Gothic UI", sans-serif`
  - ラベル枠と中央の文字も既定で JetBrains Mono を使う。
    - canvas に描く前に `document.fonts.load()` で読み込みを待つ。
    - SVG出力のときは「フォントを埋め込む」を選べる（@font-face に base64 で埋め込む。既定はオン）。
  - OFL-1.1 のライセンス表記は、OSSライセンス一覧のページに載せる。

## 1.4 非機能要件
- PWA：オフラインで完全に動作し、インストールでき、更新を通知する。
- プライバシー：入力内容はすべて端末の中で処理し、外部へ送信しない。解析ツールも入れない。
- セキュリティ：CSP（`default-src 'self'`、wasm の実行は許可）。取り込んだ画像はcanvasで再描画してメタデータを捨てる。SVG出力ではテキストをエスケープする。
- 性能：入力から再描画まで50ms以内（40型を除く）。初期表示のJSは、zxing-wasm を除いて gzip で100KB以下。
- アクセシビリティ：キーボードで操作でき、ラベルと aria を付け、ライト／ダークテーマに対応する。
- 対応ブラウザ：Chrome / Safari / Firefox / Edge の最新2版、iOS 16以降、Android 10以降。
- 表記：「QRコードは株式会社デンソーウェーブの登録商標です」をフッターに入れる。
- 対象外：SQRC、フレームQR、iQR、ほかのバーコード、サーバーでの保存・短縮URLの発行。

## 1.5 詳細仕様（既定値で決めたもの）
- **初期状態**
  - 入力の種類：URL
  - シンボル：モデル2
  - 型番：自動（入力が収まる最小の型番）
  - 誤り訂正：M
  - マスク：自動（規格の失点評価で選ぶ）
  - 余白：4セル
  - サイズ：256px
  - 色：黒と白
  - 前回の設定を localStorage に保存する。入力内容は保存しない。読み書きはすべて try/catch で囲む。
- **共有用URLは作らない。** 入力データがURLに入ってしまうのを避けるため。
- **入力チェック**
  - URL：
    - `http` / `https` 以外のスキームには警告を出す。
    - `javascript:` と `data:` は生成前に確認ダイアログを出す。
  - メール：簡易的な形式チェック。
  - 電話：数字、`+`、`-` だけを許可する。
  - Wi-Fi：SSID は必須。暗号化方式は WPA / WEP / なし。
  - vCard と VEVENT：`, ; \` と改行をエスケープする。
- **シンボルごとの機能制限**
  - UIでは、選べない組み合わせを無効にし、理由を表示する。
  - マイクロQR：
    - M1 は数字のみ、M2 は数字と英数字のみ。
    - ECI・連結・FNC1 は非対応。
  - rMQR：ECI・連結の扱いは規格書で確認して合わせる。
- **文字コード**
  - 既定：Shift_JIS で表せる文字は漢字モードかバイトモードにする。表せない文字（絵文字など）が入った場合は、区間ごとに UTF-8 のバイトモードにする。
  - 「UTF-8のECIを付ける」は選択式で、既定はオフ（ECIで誤動作する読取アプリがあるため）。
- **連結QR**
  - データを指定した個数に均等に分ける。
  - パリティは、元データ全バイトの XOR で求める。
  - 出力：個別の画像、ZIP、全シンボルを並べた1枚の画像。
- **バイナリ**：アップロードの上限は、連結16個・型番40・誤り訂正L の容量（約47KB）。超えた場合は拒否する。
- **ロゴと中央の文字**
  - ロゴ画像：PNG / JPEG / WebP、2MB以下。SVGは受け付けない（安全のため）。
  - ロゴの面積の目安：L 5%、M 10%、Q 15%、H 20%。これを超えると警告を出す。最終的な判定は読取検証で行う。
  - 中央の文字：最大4文字。囲みの形は丸・四角・なしから選ぶ。
- **ラベル枠**：文字は最大30文字。位置（上／下）、文字色、枠の色、角の丸みを設定できる。
- **一括生成のCSV**
  - 列：`content` と `filename`（任意）。
  - 文字コード：UTF-8 と Shift_JIS を自動判定する。
  - ファイル名：使えない文字を除去し、重複には連番を付ける。
- **PWAの更新**：新しい版があると「更新」ボタンを表示する（prompt 方式）。
- **その他**
  - 使っているOSSのライセンス一覧のページを作る。
  - ビジネスロジックのテストカバレッジは80%以上を目標にする。

## 1.6 推奨どおりに確定した事項
- アプリ名は「QR Studio」（短い名前「QR」）。アイコンは型番1のQR風の図案を自作する。
- 公開先は `*.vercel.app`。
- GitHub に非公開リポジトリを作る。GitHub Actions（SHAで固定）で lint・型チェック・テスト・ビルドを回し、Vercel と Git を連携する。
- このアプリのライセンスは MIT。
- 追加しない機能：
  - カメラでの読み取り（別途確認中）
  - セルの形・位置検出パターンの形・グラデーションのカスタマイズ
  - EPS 出力
  - 印刷用シートへの面付け
- 追加する機能：
  - 設定のプリセット保存（最大20件）
  - 履歴の JSON での書き出しと取り込み
  - JPEG / WebP 出力
- GS1：アプリケーション識別子の文字列をそのまま入力し、形式チェックだけ行う。
- 型番を固定していてデータが入りきらないとき：エラーを出して提案を表示する（勝手に型番を上げない）。
- マイクロQR・rMQR・型番25以上を選んだとき：スマホでの読み取りに関する注意を常に表示する。
- テストとアクセシビリティ：Playwright で主な操作の流れを E2E テストし、WCAG 2.2 AA を目標にする。
