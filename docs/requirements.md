# QR Studio 要件定義書

> QRコードは株式会社デンソーウェーブの登録商標です。


## 1.1 対応するシンボル（すべて公開規格）
| 種別 | 規格 | 範囲 |
|---|---|---|
| QRコード モデル2（既定） | ISO/IEC 18004:2015 | 型番1〜40、誤り訂正 L/M/Q/H、マスク0〜7（自動／手動） |
| マイクロQR | ISO/IEC 18004 | M1〜M4（M1は誤り検出のみ、M4は L/M/Q まで） |
| rMQR（長方形） | ISO/IEC 23941:2022 | R7x43〜R17x139 の32サイズ、誤り訂正 M/H |
| 連結（構造的連接） | ISO/IEC 18004 | モデル2で最大16シンボル。パリティは自動計算 |

## 1.2 データと符号化
- モードは数字・英数字・8bitバイト・漢字（Shift_JIS）の4つ。ECI と FNC1（GS1）も指定できる。
- 既定は「自動」で、最短になるように複数モードを混在させる。上級者向けに、区間ごとにモードを手動指定できるエディタも用意する。
- 入力の種類：
  - URL、テキスト、電話（`tel:`）、SMS（`SMSTO:`）、メール（`mailto:` / `MATMSG:`）
  - Wi-Fi（`WIFI:` 形式。特殊文字はエスケープする）
  - vCard 3.0、MeCard
  - 位置情報（`geo:`）、カレンダー（`BEGIN:VEVENT`）
  - 複数URL（改行区切りで1つのQRに入れる）
  - バイナリ（ファイルのアップロード、または16進数の入力）
- 容量オーバー時の動作：
  1. より大きい型番を提案する
  2. 誤り訂正レベルを下げることを提案する
  3. 連結QRに分割することを提案する

  この順に提案し、残り容量（ビット数・文字数）を常に表示する。
- 一括生成：複数行のテキストまたはCSVを入力すると、1行ごとに1枚のQRを作る。結果は一覧表示とZIP保存（PNG/SVG）で受け取れる。

## 1.2.1 容量テーブル（部分表示）
選んでいる種類と設定で、どれだけのデータを入れられるかを表で示す。

- 列：
  - 型番またはサイズ（1〜40 / M1〜M4 / R7x43〜R17x139）
  - 誤り訂正
  - 数字・英数字・バイト・漢字それぞれの最大文字数
  - データのビット数
  - 連結時の合計（連結数が2〜16のとき）
- 部分表示：
  - 既定では、今の設定の行を中心に前後数行だけを表示する。
  - 設定を変えると表示範囲が追従し、今の行を強調する。
  - 「全件表示」で全行（モデル2で160行、rMQRで64行、マイクロQRで8行）を開ける。
  - 誤り訂正レベルでの絞り込みもできる。
- 入力との連動：
  - 今の入力が収まる行に ✓ を付け、収まる中で最小の型番を示す。
  - 今の行には使用率のバーを出す。
  - 行をクリックすると、その型番と誤り訂正が設定に反映される。
- 計算方法：文字数は表に固定値で持たず、エンコーダと同じ表（データのコード語数）から算出する。
  - モードの指示子と文字数の指示子のビット数を差し引いて求める。
  - M1 と M3 は、末尾のコード語が4bitであることも考慮する。
  - 連結では、1シンボルあたり20bitのヘッダを差し引く。
  - こうすることで、エンコーダの挙動と表示が必ず一致する。

## 1.3 見た目と出力
- セルのサイズ（px/mm）、出力サイズ、余白（既定4セル、マイクロQRとrMQRは既定2セル）を設定できる。
- 前景色・背景色・透過背景を設定できる。コントラストが不足すると警告する。
- 中央には、ロゴ画像または囲み文字（例：①）・短いテキストを置ける。置くと誤り訂正Hを推奨し、占有面積の上限も警告する。
- 周囲に文字入りのラベル枠（例：「SCAN ME」）を付けられる。上下の位置とフォントを選べる。
- 読取検証：装飾まで含めた画像を zxing-wasm で実際に読み取り、OK か NG かを表示する。zxing-wasm は必要になった時点で読み込む。
- 出力：PNG / SVG の保存、クリップボードへのコピー、生成履歴（IndexedDB、最大100件、削除可能）。

- 印刷向けの出力：mm単位とDPI（72〜1200）を指定してPNGを作る（例：30mm角を350dpi）。印刷時のセルの大きさが0.25mm未満になると警告する。SVGはmm単位で書き出す。
- 一括生成の上限は1,000件。Web Workerで処理し、進捗を表示し、途中で中止できる。

## 1.3.1 画面と言語
- 日本語と英語を切り替えられる。既定はブラウザの言語設定に従い、選んだ言語は保存する。文言は `src/lib/i18n/{ja,en}.ts` にまとめる。
- PCとスマホを同等に扱う。
  - PC：左に入力と設定、右にプレビューと容量テーブルの2列。
  - スマホ：プレビューを上部に固定し、その下に入力、設定、容量テーブルを縦に並べる。

## 1.3.2 テーマとフォント
- **テーマ**
  - 「端末に合わせる」「ライト」「ダーク」の3つから選ぶ。既定は「端末に合わせる」。
  - 選んだテーマは localStorage に保存する。
  - 仕組み：`<html data-theme>` と CSS 変数の色トークンで切り替える。「端末に合わせる」のときは `prefers-color-scheme` を監視する。
  - `<meta name="theme-color">` をライト用・ダーク用の2本用意し、手動で切り替えたときは JS で更新する。manifest の `theme_color` と `background_color` も設定する。
  - 初回表示のちらつき防止：`index.html` の先頭に小さなインラインスクリプトを置き、描画前に `data-theme` を決める。CSP ではこのスクリプトの hash だけを許可する。
  - 注意：プレビューのQR自体の色は、テーマではなく利用者が指定した前景色・背景色に従う。
- **フォント**
  - JetBrains Mono（`@fontsource-variable/jetbrains-mono` v5.3、OFL-1.1）をバンドルに同梱する。
  - 外部CDNは使わない。woff2 を Service Worker で事前キャッシュし、オフラインでも表示できるようにする。
  - 読み込むのは latin と latin-ext のサブセットのみ。`font-display: swap` を指定する。
  - JetBrains Mono には日本語の字形がない。かな・漢字は、端末に入っている日本語フォントで補う。
    - 指定：`font-family: "JetBrains Mono Variable", "Hiragino Sans", "Noto Sans JP", "Yu Gothic UI", sans-serif`
  - ラベル枠と中央の文字も既定で JetBrains Mono を使う。
    - canvas に描く前に `document.fonts.load()` で読み込みを待つ。
    - SVG出力のときは「フォントを埋め込む」を選べる（@font-face に base64 で埋め込む。既定はオン）。
  - OFL-1.1 のライセンス表記は、OSSライセンス一覧のページに載せる。

## 1.4 非機能要件
- PWA：オフラインで完全に動作し、インストールでき、更新を通知する。
- プライバシー：入力内容はすべて端末の中で処理し、外部へ送信しない。解析ツールも入れない。
- セキュリティ：CSP（`default-src 'self'`、wasm の実行は許可）。取り込んだ画像はcanvasで再描画してメタデータを捨てる。SVG出力ではテキストをエスケープする。
- 性能：入力から再描画まで50ms以内（40型を除く）。初期表示のJSは、zxing-wasm を除いて gzip で100KB以下。
- アクセシビリティ：キーボードで操作でき、ラベルと aria を付け、ライト／ダークテーマに対応する。
- 対応ブラウザ：Chrome / Safari / Firefox / Edge の最新2版、iOS 16以降、Android 10以降。
- 表記：「QRコードは株式会社デンソーウェーブの登録商標です」をフッターに入れる。
- 対象外：SQRC、フレームQR、iQR、ほかのバーコード、サーバーでの保存・短縮URLの発行。

## 1.5 詳細仕様（既定値で決めたもの）
- **初期状態**
  - 入力の種類：URL
  - シンボル：モデル2
  - 型番：自動（入力が収まる最小の型番）
  - 誤り訂正：M
  - マスク：自動（規格の失点評価で選ぶ）
  - 余白：4セル
  - サイズ：256px
  - 色：黒と白
  - 前回の設定を localStorage に保存する。入力内容は保存しない。読み書きはすべて try/catch で囲む。
- **共有用URLは作らない。** 入力データがURLに入ってしまうのを避けるため。
- **入力チェック**
  - URL：
    - `http` / `https` 以外のスキームには警告を出す。
    - `javascript:` と `data:` は生成前に確認ダイアログを出す。
  - メール：簡易的な形式チェック。
  - 電話：数字、`+`、`-` だけを許可する。
  - Wi-Fi：SSID は必須。暗号化方式は WPA / WEP / なし。
  - vCard と VEVENT：`, ; \` と改行をエスケープする。
- **シンボルごとの機能制限**
  - UIでは、選べない組み合わせを無効にし、理由を表示する。
  - マイクロQR：
    - M1 は数字のみ、M2 は数字と英数字のみ。
    - ECI・連結・FNC1 は非対応。
  - rMQR：ECI・連結の扱いは規格書で確認して合わせる。
- **文字コード**
  - 既定：Shift_JIS で表せる文字は漢字モードかバイトモードにする。表せない文字（絵文字など）が入った場合は、区間ごとに UTF-8 のバイトモードにする。
  - 「UTF-8のECIを付ける」は選択式で、既定はオフ（ECIで誤動作する読取アプリがあるため）。
- **連結QR**
  - データを指定した個数に均等に分ける。
  - パリティは、元データ全バイトの XOR で求める。
  - 出力：個別の画像、ZIP、全シンボルを並べた1枚の画像。
- **バイナリ**：アップロードの上限は、連結16個・型番40・誤り訂正L の容量（約47KB）。超えた場合は拒否する。
- **ロゴと中央の文字**
  - ロゴ画像：PNG / JPEG / WebP、2MB以下。SVGは受け付けない（安全のため）。
  - ロゴの面積の目安：L 5%、M 10%、Q 15%、H 20%。これを超えると警告を出す。最終的な判定は読取検証で行う。
  - 中央の文字：最大4文字。囲みの形は丸・四角・なしから選ぶ。
- **ラベル枠**：文字は最大30文字。位置（上／下）、文字色、枠の色、角の丸みを設定できる。
- **一括生成のCSV**
  - 列：`content` と `filename`（任意）。
  - 文字コード：UTF-8 と Shift_JIS を自動判定する。
  - ファイル名：使えない文字を除去し、重複には連番を付ける。
- **PWAの更新**：新しい版があると「更新」ボタンを表示する（prompt 方式）。
- **その他**
  - 使っているOSSのライセンス一覧のページを作る。
  - ビジネスロジックのテストカバレッジは80%以上を目標にする。

## 1.6 推奨どおりに確定した事項
- アプリ名は「QR Studio」（短い名前「QR」）。アイコンは型番1のQR風の図案を自作する。
- 公開先は `*.vercel.app`。
- GitHub に非公開リポジトリを作る。GitHub Actions（SHAで固定）で lint・型チェック・テスト・ビルドを回し、Vercel と Git を連携する。
- このアプリのライセンスは MIT。
- 追加しない機能：
  - カメラでの読み取り（別途確認中）
  - セルの形・位置検出パターンの形・グラデーションのカスタマイズ
  - EPS 出力
  - 印刷用シートへの面付け
- 追加する機能：
  - 設定のプリセット保存（最大20件）
  - 履歴の JSON での書き出しと取り込み
  - JPEG / WebP 出力
- GS1：アプリケーション識別子の文字列をそのまま入力し、形式チェックだけ行う。
- 型番を固定していてデータが入りきらないとき：エラーを出して提案を表示する（勝手に型番を上げない）。
- マイクロQR・rMQR・型番25以上を選んだとき：スマホでの読み取りに関する注意を常に表示する。
- テストとアクセシビリティ：Playwright で主な操作の流れを E2E テストし、WCAG 2.2 AA を目標にする。


## 1.7 追加要件（2026-09-28）
- **入力量カウンター**（内容タイル）：入力中の文字数・バイト数と、使用ビット数を次の2つと比べてバーで表示する。
  - 現在のシンボル（例：2-M、連結時は「33-M × 2」）の容量
  - 設定での上限（型番「自動」なら最大の型番、分割数「自動」なら16枚。連結時は1枚あたり20bitのヘッダを容量から差し引く）
  - 使用率90%超で警告色、100%超でエラー色と超過ビット数を表示する。
- **連結QRの分割数「自動」**（既定値）：1枚に収まればそのまま、収まらなければ2〜16枚のうち収まる最小の枚数に分割する。モデル2以外では「なし」に固定する。
- **データ削減オプション**（シンボル設定。既定はすべてオフ）
  - A. URL大文字化：http(s) のスキームとホストのASCII英字を大文字にし、英数字モードで短くする。ユーザー情報・パス・クエリ・フラグメントは変えない。
  - B. 全角→半角：U+FF01〜FF5E と全角スペースを半角にする。Wi-Fi・GS1・バイナリには適用しない。
  - C. 連絡先の最小化：vCard を MeCard に切り替える。役職がある場合は vCard のまま TEL の TYPE パラメータなどを省く。
  - D. deflate 圧縮：`QZ\x01` + raw deflate（UTF-8）をバイトモードで格納する。圧縮しない場合より必要ビット数が少ないときだけ使う。ECIは付けない。標準カメラでは読めないため、画面に注意を表示する。
- **読取タブ**：カメラ（背面）または画像ファイルから QR・マイクロQR・rMQR を zxing-cpp で読み取る。連結QRは全枚数そろった時点で結合し、D形式は自動で解凍する。http(s) の結果は「開く」リンクを表示する（自動では開かない）。カメラ許可のため Permissions-Policy を `camera=(self)` にする。
- **画像入力**（入力の種類「画像」）
  - 画像（PNG / JPEG / WebP / GIF / AVIF、30MBまで。SVGは不可）を選ぶと、現在のシンボル設定の上限（型番「自動」は最大型番、分割数「自動」は16枚）に収まるまで、画質→寸法の順に下げて WebP（非対応ブラウザは JPEG）に再圧縮する。設定を変えると自動で再調整する。
  - 元ファイルがそのまま収まる場合は再圧縮しない。いずれの場合も ICC プロファイル・EXIF・XMP を除去する（canvas 出力は sRGB のため見た目は変わらない）。
  - 格納方法：バイナリ（推奨、8bit/byte）・Base64 data URL（約25%減）・Base45（RFC 9285、英数字モード、約3%減）。
  - 読取タブは、生バイト・data URL・Base64・Base45 から画像を検出してプレビューと保存を提供する。
- **位置情報の指定方法**（入力の種類「位置情報」）
  - 現在地：Geolocation API（端末内で取得し外部送信しない。Permissions-Policy `geolocation=(self)`）。
  - 地図・住所検索は外部サービスを使うため、**ボタンを押した時だけ**通信し、送信先を画面に明記する。サービスは利用者が明示的に切り替える（設定に保存）。
    - 国土地理院：地理院タイル、住所・市区町村検索（msearch.gsi.go.jp）、郵便番号は zipcloud で住所に変換してから検索。
    - OpenStreetMap：OSM タイル、Nominatim（世界中の住所・地名、日本の郵便番号は postalcode 検索）。
  - 地図（Leaflet、必要時のみ遅延読み込み）はクリックまたはピンのドラッグで位置を指定し、座標は小数6桁に丸める。検索結果のラベルは短い名称を使う（QRを小さく保つため）。
  - 外部サービスへはオリジンのみを Referer として送信し、Cookie は送らない。CSP の img-src / connect-src に各サービスのホストだけを追加する。
  - プライバシー要件を「入力内容は外部に送信しない（位置情報の地図・住所検索を使った場合を除く）」に変更。

## 1.8 バーコード生成（2026-09-28）
参考：BarcodeOcean（種類・バーの高さ／幅・上下左右の余白・文字サイズ／位置・フォント・色・透過・px/mm 表示・一括生成・連番）、TEC-IT（チェックデジット・Full ASCII・ベアラーバー・アドオン）。
- **切り替え**：上部リボンの「QRコード／バーコード」タブで切り替える（設定に保存）。バーコード側のタブは「生成・一括生成・読取・履歴」。
- **上部リボン**：画面上部に常に固定する。1行目にロゴ・タイトル、コードの種類タブ（QRコード／バーコード／Data Matrix）、表示設定ボタン（歯車。テーマと言語のメニュー、外側クリックや Esc で閉じる）。2行目に機能タブ。スマホではタイトルを省いて同じ2行に収める。右カラムの固定表示やフォーカス時のスクロール位置はリボンの高さを差し引く。
- **対応シンボル**（エンコーダは自作。bwip-js と同じバー幅になること、zxing-cpp で読めることをテストで確認）
  - 流通：EAN-13 / JAN-13（ISBN-13 含む）、EAN-8 / JAN-8、UPC-A、UPC-E（UPC-A からの短縮も可）、EAN-2 / EAN-5 アドオン。チェックデジットは自動計算、入力されていれば検査する。
  - 物流・産業：Code 128（コードセット A/B/C と SHIFT を動的計画法で最短化）、GS1-128（(AI)値 形式。QR の GS1 と同じ解析・検査）、Code 39（mod 43・Full ASCII 任意）、Code 93（Full ASCII、チェック文字2つ）、ITF（mod 10 任意）、ITF-14、NW-7（Codabar、スタート/ストップ A〜D）。
  - その他：Code 128 A/B/C 固定、MSI（なし・Mod 10・Mod 11・Mod 1010・Mod 1110）、Pharmacode（3〜131070）。
  - 太細比（Code 39・ITF・ITF-14・NW-7）：1:2 / 1:2.5 / 1:3（既定 1:3）。
- **デザイン**：バーの高さ、左右余白（既定は規格の最小値：EAN-13 は左11・右7 など）、上下余白、文字の表示／位置（下・上）／サイズ／間隔、フォント（JetBrains Mono 埋め込み・端末のゴシック／明朝／等幅）、前景色・背景色・透過、ベアラーバー（なし・上下・枠。ITF-14 選択時は枠を既定にする）。EAN/UPC は数字をガードバーの間に配置し、ガードバーを延長する。長さは出力単位（px または mm）で表示・入力し、内部ではモジュール単位で保持する。
- **出力**：PNG / SVG / JPEG / WebP、画像のコピー、データのコピー。
  - px 指定：細バー幅（1〜20 px、整数）。
  - mm 指定：X寸法（細バー幅 mm）＋ dpi。画像出力はバー幅を正確に保つため、1モジュールを整数ドットに丸める（丸めた X寸法を表示・警告）。SVG は指定どおりの mm。EAN/UPC で X寸法が 0.264〜0.660 mm の範囲外なら警告する。
- **読取検証**：zxing-cpp で読み取り、期待値（UPC は EAN-13 形式、Codabar はスタート/ストップ付きなども許容）と比較する。MSI と Pharmacode は読取非対応のため無効にする。読取タブも主なバーコードを読み取る。
- **一括生成**：1行1件または CSV（content, filename）で最大1,000件を ZIP にまとめる。連番作成（先頭・末尾の文字、開始番号、増分、件数、0埋め桁数）を備える。失敗した行は理由を表示する。
- **性能**：バーコード画面は初めて開いたときに読み込む（初期表示 JS の gzip 100KB 以下を維持）。

## 1.9 バーコードの履歴と Data Matrix（2026-09-28）
- **履歴**：バーコードも「履歴に保存」で QR と同じ履歴（最大100件、JSON 書き出し／読み込み）に保存する。種類・データ・オプション・デザインを保存し、出力設定は保存しない。履歴は「すべて／QRコード／バーコード」で絞り込め、初期表示は現在のモード。「開く」でモードを切り替えて復元する。読み込んだ値は設定の正規化を通してから使う。
- **Data Matrix（ECC 200、ISO/IEC 16022）**：QRコード・バーコードとは別の2次元コードとして、上部リボンの「Data Matrix」タブで切り替える（生成・一括生成・読取・履歴）。種類は「Data Matrix」「GS1 DataMatrix」。設定（種類・オプション・デザイン・出力）はバーコードとは別に保存し、文字表示は既定でオフ。
  - 符号化：ASCII（数字2桁で1コードワード、拡張文字は上位シフト）・C40・Text・Base256 を動的計画法で組み合わせて最小にする。Latin-1 で表せない文字は UTF-8 + ECI 26。GS1 は先頭と区切りに FNC1。X12・EDIFACT・連結（Structured Append）は対象外。
  - サイズ：正方形 24種（10×10〜144×144）・長方形 6種（8×18〜16×48）。形（正方形・長方形・最小になる方）とサイズ（自動・固定）を選べる。入りきらない場合は必要／最大コードワード数を表示する。
  - 検証：全30サイズで bwip-js と同一のモジュール配置（誤り訂正・パディング・144×144 の特殊インターリーブを含む）、zxing-cpp での往復をテストする。
  - デザイン：四辺の余白（既定2セル）、文字（シンボル幅に収まるよう自動縮小）、色・透過。バーの高さ・上下余白・ベアラーバーは表示しない。
  - 出力：1セルのピクセル数（既定 8 px）または 1セルの大きさ mm（既定 0.5 mm）+ dpi。バーコードの細バー幅とは別に保存する。
  - 読取タブと読取検証も Data Matrix を読み取る。
